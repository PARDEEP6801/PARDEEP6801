# Pardeep Projects

| Folder | Kya hai | Kaise chalaye |
|---|---|---|
| `ai-studio/` | NVIDIA / OpenRouter ke saare models + apni custom LLM banane wala localhost app | `.env` mein key daalo, phir `npm run dev` |
| `tradingview-indicator/` | TradingView ke liye BUY/SELL + SL/TP indicator | `.pine` code Pine Editor mein paste karo |

Har folder ke andar apni `README.md` hai, usme step-by-step guide hai.

## Install / Update (Windows)
`Update-Projects.bat` pe double-click karo. Ye GitHub se latest project le aata hai aur `Desktop\Pardeep-Projects` mein daal deta hai.
Pehli baar mein folder ban jayega. Uske baad jab bhi naya model ya feature aaye, dobara double-click kar dena.
Aapki `.env` (API key) aur banayi hui LLMs kabhi overwrite nahi hoti.
